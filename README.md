# Voyager · 旅行者

驾驶飞船穿越无尽星海,俯冲降落在陌生的星球,扫描从未见过的动植物。每一颗星球,都有一个只属于它的坐标码。

**[▶ 在线玩最新版](https://link1412.github.io/voyager/)** · [所有版本](#版本) · [下载](https://github.com/link1412/voyager/releases)

整个游戏是一个 HTML 文件。地形、天空、云、海、植物、动物、飞船、音乐和音效,全部由代码在你的电脑上实时生成,文件里没有一张图片、一段录音。不用安装,不用联网:下载后双击就能玩。

## 需要什么

- 电脑,键盘加鼠标。手机和平板玩不了。
- 较新的浏览器:Chrome / Edge 80、Safari 16.4、Firefox 113 或更新的版本。
- 一块像样的显卡。游戏会自动降低分辨率,或者改成 30 帧来保持流畅;还是卡的话,看下面的「电脑带不动时」。

## 操作

| | |
|---|---|
| 飞船 | 鼠标 转向 · W / S 油门 · A / D 滚转 · Shift 加速 · 空格 巡航 · G 降落 / 起飞 · E 出舱 |
| 步行 | W A S D 移动 · 空格 跳跃 / 喷气背包 · Shift 奔跑 · C 召唤飞船 · E 回到飞船 |

## 星球坐标码

每颗星球都有一个坐标码,比如 `0-0-0-2`。在标题画面输入坐标码,就能直接飞过去;旁边的骰子会随机给你一颗。游戏里按 P 会得到当前星球的分享链接,在线版的链接发给朋友,点开就是同一颗星球。

坐标码只在生成它的那个版本里有效:新版本如果改了宇宙的生成方式,同一个码可能会变成另一颗星球。所以每个版本都有自己固定的网址(见下面的版本表),分享时用带版本号的链接最稳妥。

## 电脑带不动时

在网址后面加参数。在线版和下载的文件都可以,直接加在浏览器地址栏里:

- `?scale=0.5`:降低渲染分辨率
- `?fps=30`:固定 30 帧

两个可以一起用:`https://link1412.github.io/voyager/?scale=0.5&fps=30`

## English

**Voyager** is a procedural planet-travel game that runs in your browser. Fly a ship through an endless galaxy, land on strange planets, walk among plants and animals no one has seen before. Every planet has its own coordinate code: share it, and a friend lands on the same world.

The whole game is a single HTML file. Terrain, sky, clouds, sea, life, ship, music and sound are all generated by code on your machine; the file contains no images or recordings.

**[▶ Play the latest version](https://link1412.github.io/voyager/)**, or download a version from [Releases](https://github.com/link1412/voyager/releases) and double-click it.

You need a computer with a keyboard and mouse (phones and tablets won't work), Chrome / Edge 80, Safari 16.4, Firefox 113 or newer, and a reasonable graphics card. On a slow machine, add `?scale=0.5&fps=30` to the address. The interface is in Chinese; press **H** in the game for the controls.
